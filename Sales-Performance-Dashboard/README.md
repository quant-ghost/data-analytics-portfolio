# Sales Performance Dashboard

## Project Overview

This project focuses on analyzing sales performance, revenue trends, product contribution, and website activity through an interactive Power BI dashboard.

The dashboard provides a comprehensive overview of business performance by combining key sales indicators, revenue trends, product-level analysis, and website session metrics into a single reporting environment.

Microsoft Excel was used for data preparation and organization, while Power BI was used to develop the dashboard and create interactive visualizations.

## Business Objective

The main objective is to monitor sales performance, evaluate revenue growth, identify top-performing products, analyze product revenue distribution, and provide insights that support data-driven business decisions.

## Data Sources & Workflow

The project follows a data preparation and visualization workflow:

- **Microsoft Excel** – Used to organize, prepare, and structure the data for analysis.
- **Microsoft Power BI** – Used to transform prepared data into interactive visualizations, KPI cards, and analytical reports.

The prepared data was imported into Power BI, where the dashboard was developed to present sales performance and product insights in a clear and structured format.

## Tools & Technologies

- **Microsoft Excel** – Data preparation, organization, and initial analysis.
- **Microsoft Power BI** – Data modeling, data visualization, and interactive dashboard development.

## Data Analysis & Preparation

- Organized and prepared sales datasets using Microsoft Excel.
- Imported prepared data into Power BI.
- Structured key performance indicators (KPIs).
- Analyzed revenue trends over time.
- Evaluated product-level revenue contribution.
- Compared top-selling products.
- Developed visual reports to support business performance monitoring.

## Key Metrics

The dashboard tracks the following key performance indicators:

| Metric | Value | Description |
|---|---:|---|
| Revenue | $1.939M | Total generated revenue |
| Total Orders | 32.31K | Total number of orders |
| Total Returns | $85.34K | Total value of returns |
| Website Sessions | 472.87K | Total website sessions |

## Dashboard Features

- **Revenue Growth Trend:** Visualizes revenue changes over time and highlights growth patterns.
- **Revenue Share by Product:** Shows how individual products contribute to total revenue.
- **Top Selling Products:** Identifies and compares the highest-revenue-generating products.
- **Sales Performance Monitoring:** Provides an overview of key business performance indicators.
- **Revenue Analysis:** Helps evaluate overall revenue performance and identify trends.
- **Website Activity Monitoring:** Includes website session metrics to provide additional business context.

## Business Value

The dashboard transforms raw sales data into meaningful business insights by providing a centralized view of revenue, orders, returns, and product performance.

It helps businesses:

- Monitor overall sales and revenue performance.
- Identify top-performing products.
- Understand which products generate the highest revenue.
- Track revenue growth and historical trends.
- Monitor product returns.
- Evaluate website activity alongside sales performance.
- Support better business planning and data-driven decision-making.
