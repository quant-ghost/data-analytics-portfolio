# SEO & Web Analytics Dashboard

## Project Overview

This project focuses on analyzing website traffic and SEO performance through an interactive Power BI dashboard.

The dashboard combines data from Yandex Metrica and Google Search Console to provide a unified view of website traffic, user engagement, and search performance.

## Business Objective

The main objective is to monitor website performance, identify traffic trends, evaluate SEO effectiveness, and support data-driven decision-making.

## Data Sources & Workflow

Data was collected from two primary sources:

- **Google Search Console** – SEO performance data, including clicks, impressions, and click-through rate (CTR).
- **Yandex Metrica** – Website traffic and user engagement data, including users, visits, and bounce rate.

Google Sheets was used as an intermediate tool to collect and organize data exported from both sources.

After preparing and organizing the datasets in Google Sheets, the data was connected to Power BI to develop an interactive dashboard combining SEO and website analytics.

## Tools & Technologies

- **Google Search Console** – SEO data collection.
- **Yandex Metrica** – Website analytics data collection.
- **Google Sheets** – Data collection, organization, and preparation.
- **Power BI** – Data integration, visualization, and dashboard development.

## Data Analysis & Preparation

- Collected data from multiple analytics platforms.
- Exported and organized datasets in Google Sheets.
- Prepared data for integration into Power BI.
- Structured key performance indicators (KPIs).
- Analyzed website traffic trends and SEO performance.
- Developed interactive visualizations and filters.

## Key Metrics

The dashboard tracks the following key performance indicators:

## Metric  Description 

  Total Users   Number of website users 
  Total Visits   Number of website visits 
  Bounce Rate   Percentage of visits with no further engagement 
  Total Clicks   Clicks from Google Search 
  Total Impressions   Search result impressions 
  CTR   Click-through rate from search results 

## Dashboard Features

- Website traffic dynamics over time.
- SEO performance monitoring.
- Search query analysis.
- Clicks, impressions, and CTR analysis.
- Interactive date filtering.
- KPI cards for monitoring key performance indicators.
- Combined view of website analytics and search performance.

## Business Value

The dashboard provides a centralized view of website analytics and SEO performance, helping monitor traffic changes, evaluate search visibility, identify trends, and discover potential areas for improvement.
